# Portail invité MikroTik

> Backend Go du portail invité : consentement, appareils approuvés, historique des connexions et paiement via ifay.

## En bref

- Consentement de l'invité avant l'accès au réseau.
- Appareils approuvés et historique des connexions.
- Paiement de l'accès via [ifay](https://github.com/daniel-langio/ifay).
- Interface traduite et migrations de base de données.

## Stack

Go · Docker · Cloud Build
